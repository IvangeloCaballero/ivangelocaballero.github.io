Modular Filtration Skid - Mechanical Layout Design

Piping system layout and flow design.

Overview

This project involves the design of a modular filtration skid, focusing on piping layout, flow routing, and component arrangement. The system integrates process functionality with considerations such as accessibility, structural support, and material estimation.

Design Basis

The system design was guided by assumed operating conditions and standard engineering practices typically applied to compact filtration systems.

  • Working Fluid: Water (clean / lightly contaminated)
  • Flow Rate (Design): 3 m³/hr
  • Operating Pressure: 6 bar
  • Design Pressure: 12 bar
  • Temperature Range: Ambient conditions (25–35°C)

Piping and components were aligned with ASME B31.3 guidelines, with consistent use of ASME B16.5 Class 300 ratings across primary connections.

Conceptual Layout and Process Flow

The conceptual floor plan illustrates the spatial arrangement of components while the process flow diagram defines system operation and flow direction.

System Layout Development

The system layout was refined using orthographic and isometric views to validate spatial relationships and integration.

Component Design and Standard Integration

The system incorporates both custom-designed components and standard parts from Inventor Content Center.

  • Custom modeling of tanks, filter unit, pump setup, control panel, support and skid frame
  • Use of Inventor Content Center for valves and piping
  • Standardized Class 300 flange usage
  • Defined sectional flange geometry

Reference: ASME B16.5 Class 300 flange tables
